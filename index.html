BTC 장기 가격 차트 (메이어 배수 구간 색상)

가격 로그 스케일 · 바이낸스 BTCUSDT 상장(2017년 8월) 이후 전체 일봉 데이터 기준. 선 색깔은 그 날의 "메이어 배수"(현재가 ÷ 200일 이동평균) 구간을 나타냅니다 — MVRV Z-Score 차트를 보는 방식과 동일한 개념입니다. 단, 이건 온체인 실현가치가 아니라 순수 가격 데이터로 계산한 근사 지표입니다.

< 1.0 저평가(과거 사이클 저점권) 1.0~1.5 중립 1.5~2.4 다소 과열 > 2.4 역사적 과열(과거 사이클 고점권)

메이어 배수 추이

1.0 아래(파란 점선)는 역사적으로 매수 관심 구간, 2.4 위(빨간 점선)는 역사적으로 과열 구간으로 언급되어온 임계값입니다. 절대적 기준은 아닙니다.

공포·탐욕 지수

0에 가까울수록 극단적 공포(패닉 매도 구간), 100에 가까울수록 극단적 탐욕(과열 구간). 극단값 자체가 종종 단기 반전 신호로 언급됩니다.

알트코인 시즌 지수 (참고용)

시가총액 상위 50개 코인 중, 최근 90일간 BTC보다 더 많이 오른 코인의 비율입니다. 75 이상이면 통상 "알트시즌", 25 이하면 "비트코인 시즌"으로 분류됩니다.

불러오려면 "새로고침"을 눌러주세요 (무료 API 호출 제한 때문에 자동 실행하지 않습니다)

사이클 지표 데이터 출처: 가격(메이어 배수 계산용) — 바이낸스 공개 API(무료, 키 불필요, 2017년 8월~) · 시총·도미넌스·알트시즌 — CoinGecko 공개 API(무료, 키 불필요) · 공포탐욕지수 — Alternative.me(무료, 키 불필요). 메이어 배수는 실제 온체인 MVRV가 아니라 가격만으로 계산한 근사 지표이며, 모든 지표는 과거 패턴을 보여줄 뿐 미래를 보장하지 않습니다.

기간별 BTC 대비 상대강도

선택 기간 동안 (알트 수익률 − BTC 수익률). 오른쪽(민트)일수록 BTC보다 더 잘 오른 코인, 왼쪽(코랄)일수록 BTC보다 못한 코인입니다. 10%p 단위로 색이 진해집니다. 최근 상장된 코인은 상장 이후 전체 기간으로 계산됩니다.
